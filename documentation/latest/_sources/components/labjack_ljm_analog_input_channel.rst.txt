LabJack LJM Analog Input Channel
================================

*Available on macOS*


Description
-----------
Analog input channel on a `LabJack LJM Device`.

If both `range_min`_ and `range_max`_ are specified, the channel will use
the narrowest supported analog-input range that includes the provided
limits. Otherwise, the default analog-input range will be used.



Signature
---------
``iochannel/labjack_ljm_analog_input``


Required Parameters
-------------------

line
^^^^
:Examples: | ``AIN0``
           | ``ain3``

Analog input line name

value
^^^^^

Variable in which to store input voltage values



Optional Parameters
-------------------

range_min
^^^^^^^^^
:Example: ``-10.0``

Minimum expected input voltage

range_max
^^^^^^^^^
:Example: ``10.0``

Maximum expected input voltage
